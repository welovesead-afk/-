# SEA.D 업무통합 시스템 — 진행 기록 · 결정 사항

최종 갱신: 2026-09-29 · 브랜치 `claude/food-erp-mes-qms-plm-crm-lg49xb`
시안 주소: https://welovesead.mycafe24.com/erp/ (예시 데이터, 브라우저에만 저장)

## 1. 목표와 단계
- 최종: ERP + MES(생산) + QMS(품질) + PLM(제품개발) + CRM(영업·수출) + 업무표준화를 한곳에
- **1단계(진행 중)**: 기준정보(품목·BOM·거래처) + 입고·생산·재고·로트 연결 + 판매 기록 + 클레임 추적
- 사용자: 직원 5명(대표 + 직원). 직원용 휴대폰 화면, 대표용 현황 화면

## 2. 사용자가 정한 원칙
- 기록은 삭제하지 않는다. 취소(사유 필수) + 수정 이력(누가·언제·무엇을)
- 접속 정보는 `.env` 또는 GitHub Secrets에서만 읽고 코드에 쓰지 않는다
- 기존 구글드라이브 파일은 읽기만 한다(사본 xlsx로 받아 읽음)
- 작업 전 계획을 먼저 보여주고 단계마다 확인받는다
- 회사 원본 자료(엑셀·PDF, 금액 포함)는 저장소에 올리지 않는다(`.gitignore`)

## 4. 검토 중 (사용자 제안, 결정 대기)
- **파란 박스 시리얼**: 내포장 후 규격별로 파란 박스에 담아 보관 → 박스 1개 채울 때마다 라벨(시리얼·규격·수량·소비기한·작업일·작업자·QR) 부착 → 외포장 때 박스 시리얼 선택/스캔 → 클레임 시 박스 단위(=작업 단위)까지 추적
  - 정할 것: 시리얼을 '채울 때마다 새 번호'(권장) vs '박스 고유 번호', 라벨 프린터, 인자기에 짧은 코드 추가 가능 여부

## 5. 사용자 답변을 기다리는 질문
1. 매출장부 선물세트 표기 확정: '씨드 기장미역 종합세트'(264건), '종합세트C'(269건), '미역＆다시마 선물세트 5종'(220건), 3종세트 D·E, 실속세트 A·B, 베어리하트, 자숙전복(신규?)
2. 기초재고 기준: (가) 26-01-01 재고 자료 / (나) 9월 말 실사로 시작, 1~9월은 분석용
3. 금액 없는 매출 1,152줄(주로 전화·기타 주문)의 의미
4. 신규 가공품(페스토·피클·아이올리·미역수프·다시마 국수) 제조 방식, 다시마 피클 규격(150g vs 250g)
5. 외포장 기준표 손글씨 판독 확인(3종 OUT 150?, 갑화량곡·부산바다 시간), 다시마 300g·500g 빨간 수정 의미
6. Supabase 프로젝트 생성(서울), 카페24 DB 비밀번호 GitHub Secrets(`DB_PASSWORD`) 등록
7. 보안: FTP/DB 비밀번호가 대화에 노출됨 → 카페24에서 변경 권장
